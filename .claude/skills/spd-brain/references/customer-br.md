# カスタマーブランディング

## 考え方の骨格
- 長く愛されるブランドになるには、ブランドの「パートナー」を増やす。パートナーは流行・機能・価格で選ばず、商品・サービスが生まれた背景と想い（ストーリー）に共感し、周りにも伝播してくれる。
- ブランドパートナーを毎年積み上げるストック型の活動。パートナーが次の顧客を連れてきて、好循環を生む。
- **Why**（ゴールデンサークル）：なぜこのブランドは生まれ、存在意義は何か。スペックや価格で選ばれると、スイッチされやすい。Whyに共感した顧客は、忠誠心のあるファンになる。
- **理念を象徴する商品・サービス**が、ファン化を加速する（理念 → 商品・サービスで体感）。単なるプロモーションより効果的。インナーにも効く（理念と現場が言行一致している実感、誇り）。

## 顧客の4区分
- 軸：LTV（顧客生涯価値）への貢献度 × 新規顧客獲得コスト（CPA）低下との関係。
- ブランド・パートナー（両方大）／ブランド・キャスター（周囲に広める）／ブランド・サポーター（長く使う）／一般顧客。
- 問い：どの区分を増やすための案か？

## 全体像：「象徴化」→「体験化」
1. **象徴ブランド開発（象徴化）**：理念を象徴的に体現した商品・サービスを、①既存のブランドリニューアル、または②新規開発する。
2. **ブランド体感の設計（体験化）**：コミュニケーション、イベント、WEB・SNS、空間、広告・PR。KBI（キー・ブランディング・インデックス）を設定してPDCAを回す。

## 象徴ブランド開発：ブランドコアの4つの観点
| 観点 | 問い |
|---|---|
| 意義性 | 社会的な意義（ミッション・ビジョン）は何か？ 解決する課題は？ |
| 独自性 | 他社と明らかに違う強みは？ それを生み出し続ける仕組み（源泉）は？ |
| 貢献性 | ブランドパートナーのベネフィット（機能・情緒）は？ 購入する理由は？ |
| 将来性 | 市場を生むか？ 社会の変化を捉えているか？ カテゴリーリーダーになれるか？ |
- 独自性だけで将来性がないとジリ貧になる。将来性だけで独自性がないと負ける。意義があるから社員のモチベーションが保たれ、世の中の共感も得られる。

## 象徴ブランド開発の「8つの問い」（社内ワークブック化の構想）
1. 課題の特定：ミッションを実現するために、何の課題を解決するか？
2. 顧客（ブランドパートナー）：対象は誰か？（属性・行動習慣・マインド）
3. 未充足ニーズ：その人の満たされていないニーズは？
4. 業界の常識：常識は何か？ どう変えて新常識にするか？
5. 伸びる兆し：これから求められそうか？ 兆しはあるか？
6. 独自の強みと仕組み：他社と違う強みと、それを生み出し続ける源泉（設備・技術・ビリーフ）は？
7. 顧客ベネフィット：購入する決定的な理由は？
8. ブランドコアと世界観：以上を凝縮したブランドコアは？ ネーミング・コピー・VIへの展開は？
- 運用の注意：凝り固まった業界・組織には、問いから議論させるだけでなく、**たたき台を先に持っていく**。顧客から問うか、課題から問うかは、相手の状況（温度感・視座をそろえたいか）で選ぶ。

## 象徴ブランド開発のプロセス
1. **コンセプトのワーディング**：4つの観点を踏まえ、短い言葉でブランドのポジションを言語化（ブランドコア）。
2. **キャラクタライズ**：パーソナリティマップでブランドパーソナリティを決め、パーソナリティストーリーに落とす。
3. **シンボライズ**：ネーミング、スローガン、ロゴ・パッケージ（VI）に落とす。イメージコラージュを持ち寄って議論する。
4. **ブランドテスト**：リリース前に、ブランドパートナーに近い人へグループインタビュー。**一切説明せず**、コンセプトシートを自分で読んでもらい、気になる点を聞く。市場に出たら「説明」ができないため。

## ブランド体感の設計
- ブランドパートナー化には2ステップ：①商品・サービスが好きになる（価値をしっかり届ける）→ ②会社を好きになる（社員との対話、ミッション体感の場・機会）。会社への共感が強まると、他商品への興味も上がる。
- **差別化ではなく差積化**：ブランディング活動がストックされることで、真似されにくさが増える。
- 3つの観点で、差積化できるコンテンツを企画する：①ブランドコアの具現化 ②社員と会える＝理念の共有 ③周囲に広めたくなる仕掛け・場。KBIを定めて継続実行する。

## 事例パターン（固有名詞は伏せる）
- **環境系ゴミ袋**：「ふだんのゴミ捨てで、CO2削減」。意義＝プラの悪者イメージを「使うほど環境に良い」に反転。独自性＝価格を上げない（自社の強みの工場で実現）。貢献性＝環境意識が高い人ではなく、一般の人の「ちょっと良いことしている感」。将来性＝「安さ」「破れない」に「環境に良い」という新しい軸をつくり、新カテゴリーのリーダーに。ネーミングは「No CO2＝No cooで、nocoo」のように、棚でも営業でも説明しやすい設計。体感施策は、ゴミ拾い、学園祭協賛、出前授業、行政との推奨・指定化など。
- **老舗酒造の若者向け新商品**：常識（ボトル＋氷＋水）を疑い、「炭酸で割って遊ぶ酒」という新常識を設定。ミッションと商品の世界観（名前の由来、パーソナリティ2〜3つを商品が持つ）を結ぶ。※社外秘の勉強用資料のため、案には転用せず、型だけ使う。

## 発想に使う問い
- 「この会社の理念を、1つの商品・サービス・体験で象徴するなら、何か？」
- 「お客様が『誰かに話したくなる』のは、どの背景・ストーリーか？」
- 「業界の誰もが当たり前だと思っている売り方を、1つ裏返すと？」
- 「社員と会える・触れられる場は、どこにつくれるか？」

## ワークブック（象徴ブランド開発の枠：CustomerBranding_flame）
ブランドアイデンティティ開発を、1枚のフレームで整理する。横軸は「理念の実現（整合性）→ 意義性 → ブランドパートナー（BP）→ 将来性 → 独自性 → 貢献性 → ブランドアイデンティティ体系」。1商品＝1行で書く。

| 列 | 書くこと |
|---|---|
| ミッション | 企業のミッション（整合性の確認） |
| 何の課題を解決するのか（意義性） | ミッションを実現するために、この商品・サービスが担う役割 |
| 顧客は誰か（BP） | 属性、価値観、行動習慣、利用シーン |
| どの市場か（将来性） | これまでの業界常識 → これからの新常識（＋伸びる兆し＝事実） |
| 独自の強みは（独自性） | 他社と明らかに違う強み |
| ★強みを生み出す源泉 | その強みを出し続けられる仕組み（製法・教育・体制）。事実で証明する |
| ベネフィットは（貢献性） | 購入する理由（機能・情緒） |
| ブランドアイデンティティ体系 | ブランドコンセプト／ネーミング／スローガン／ストーリー／パーソナリティ／ロゴ・VI |

### ワークショップの進め方（目安：約5か月、Day1〜11）
| Day | テーマ | 問い（共有OK） |
|---|---|---|
| Day1 | 意義性 | ミッションを実現するために、「社会・世の中の何の課題」を解決するか？（この商品・サービスは、ミッション実現のために何の役割を担うのか） |
| Day2 | ブランドパートナー | どんな人か？（性別〔ジェンダー配慮〕、年齢、職業、性格／大切にしている価値観、平日／休日の過ごし方、どんなシーンで利用するか）／満たされていないニーズは？（他の商品・サービスで満たし切れていないもの） |
| Day3 | 業界の常識・将来性 | これまでの業界の常識は？（他社の売り方、購入される理由、世の中の流れとずれている部分、競合分析）／これから求められそうなニーズと、その兆し（＝事実）は？ |
| Day4 | 独自性 | この商品（自社）ならではの、他社と明らかに違う独自の強みは？／その強みを生み出し続ける仕組み（製法・教育など）は？ → 具体的な事実を列挙する |
| Day5 | 貢献性 | 独自のベネフィットは？ つまり、他社ではなくこの商品を「購入する理由」は？ |
| Day5〜8 | 提案＆ディスカッション | コンセプト、ネーミング、スローガン、ストーリー、パーソナリティを、提案して議論する |
| Day9〜10 | VIワークショップ | ロゴ・VI（`vi.md` 参照） |
| Day11 | コンセプトテスト | コンセプトシートを準備し、グループディスカッション（3人1組・1.5時間を2組以上）。**説明は一切しない**。読んでもらった上で、①いいと思った点（具体的な言葉・デザイン）②懸念される点 ③さらに良くなる点（「これがこうなったら買いたい」を具体的に）を聞く。結果を踏まえて最終調整 |

### ワークブックにある事例のパターン（クライアント名は伏せる。社外秘の表示がある事例は、内容を転用しない）
- 事例の型：「ミッション → 課題 → 顧客 → 市場（常識／新常識） → 強み → 源泉 → ベネフィット → コンセプト → ネーミング → スローガン → パーソナリティ」が、1行でつながっている。
- 例の型（高齢者向けサービス）：課題「一人時間を持て余す」→ 象徴サービス「入居者のためのラジオ番組」→ ベネフィット「ときめき（お便りが読まれる、リクエストが流れる）」→ スローガン「一人時間にときめきを。」
- 例の型（補聴器）：常識「聞こえればいい（モノ売り）」→ 新常識「人生を楽しむためのツール（テクノロジーと伴走）」。
- 強みの源泉は「証明できる事実」で書く（資格者の人数、産学連携のエビデンス、製法・設備の導入など）。
