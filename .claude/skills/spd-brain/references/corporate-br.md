# コーポレートブランディング（CI／MI）

## 考え方の骨格
- パラドックスのブランディング＝「志ブランディング」。差別化（明確な意義のある独自性）と、経営の一貫性が要点。
- 「あの木はなぜ1000年も生き続けられるのか」＝揺るぎない幹と根（コーポレートアイデンティティ）がある。
- 不易流行：不易（変えてはならない使命・価値）と流行（変えていく日々の活動）の両方を意識した経営が、長期的な利益につながる。
- 100年単位で考えると経営者も「流行」の一部。全員が志を見据えた経営ができれば、経営者が変わっても会社がぶれない。

## CIの全体像
- **MI（Mind Identity）理念**：MISSION／VISION／VALUE／SPIRIT／PERSONALITY／SLOGAN ＝ 理念の統一
- **VI（Visual Identity）**：LOGO／COLOR／FONT／KEY VISUAL／GUIDELINE ＝ 視覚の統一
- **BI（Behavior Identity）**：HR POLICY／BUSINESS POLICY ＝ 行動の統一
- 時間軸：長期（30年〜・創業の精神）／中長期（5年〜・競争優位の源泉）／短中期（1〜5年・経営計画）。

## MIの4要素＋ブランドを伝える2要素
| 要素 | 意味 |
|---|---|
| Mission | 企業が存在する意味。日々果たすべき使命 |
| Vision | ミッションを追求し続けた先で実現させたい未来 |
| Value | 世の中に提供する卓越した価値（約束する価値・強み）。社員の行動指針の意味もある |
| Spirit | 大切にすべき精神・価値観 |
| Slogan | 企業の理念を世の中に伝える合言葉 |
| Brand Story | 価値観の背景にある、独自性・必然性のあるストーリー |
- 軸：顧客軸／社員軸／未来軸。

## 言語化のポイント
1. **SEEDSとNEEDSをつなぐ**：企業のSEEDS（らしさ・価値観・創業者の原体験・創業時の強み・現在のらしさ）と、社会のNEEDS（時代・社会の課題・要請）の接点から、必然性のある「ブランドストーリー（言魂）」をつくる。
2. **ミッションの意義の深さ**：目的のレイヤーを高めると、マーケットが広がり、働く誇りと成長の伸びしろが生まれる。
3. **プロジェクト化して巻き込む**：参加者の所有感が浸透効果になる。
4. **セッション形式で均等に意見を出す**：付箋に書き出す形式で、経営視点を高める研修効果もある。

## 言語化〜浸透のフロー（目安）
- 3時間×12〜14回、約6か月。プロジェクトチーム（ボードメンバー6〜12名）立ち上げ → 事前調査（PJメンバーインタビュー、サーベイ）→ ワークショップ（経営課題の整理、メモリアルワーク＝伝説の仕事共有、経営者インタビュー、DNA・らしさ考察、SEEDS×NEEDS、未来小説・未来年表）→ ミッション／ビジョン／バリュー／スピリット／スローガン／パーソナリティの言語化 → 達成すべき成果の設定 → 浸透フェイズ（BI・VIの開発、アドバイザリー）。

## 発想に使う問い
- 「この会社にしか果たせない志は何か？」「社会・時代の課題・要請は何か？」
- 「メモリアルワーク（人生・仕事の転機となった仕事）は何か？」「伝説の仕事は？」
- 「5〜10年後、世の中からどんな存在として認知されていたいか？」
- 「あえてやらないこと／あえてやっていることは何か？」

## 言葉の型（案を出すときの参考。固有名詞は案件ごとに差し替える）
- Mission：「〇〇で、△△をつくり続ける。」「〇〇に関わるすべての人の成長を実現する。」
- Vision：「〇〇を、△△の常識に。」「〇〇を、人気の職にする。」（名詞を裏返す型）
- Value：「本質を極めた独創性」「察知する力／企てる力／完遂する力」（3つの“力”に分ける型）
- Spirit：動詞の命令形で短く（「挑戦し続けよ」「妥協するな」「仲間に貢献せよ」）。

## 伝え方の注意
- 「言葉をつくることはゴールではなくスタート」。MIを起点に、アウター領域（営業・品質・商品・広報・PR）とインナー領域（社内活性・人事・育成・採用）へ展開する。
- 提案では、ブランディング効果の数字（売上成長率など）を使う場合、出典（調査対象・期間）を確認する。
