# visions（志でつながるブランディングプラットフォーム）

## visionsとは
- パラドックスが運営する、「掲げた理念をひたむきに追求している企業」と「仕事に生きがいや人間的成長を求める人々」が、志で学びつながるプラットフォーム。合言葉は「志の叶え合い」。
- WHY：日本の仕事観（規模・知名度・条件面という外側のモノサシ）を変え、「はたらく」を「面白く生きる」へ。衣食住に続いて「働」も、価値観やスタンスで選ぶ時代へ。
- 志とは：「こころざし。それは、こころが指す方角。」強みや個性の先にある、その人らしい社会への役立ち方。
- 企業向け（企業ブランディング＝次世代の志育成に貢献しながら認知をつくり、理念を共に創る人材とつながる）と、個人向け（パーソナルブランディング＝さまざまな企業や仕事に触れ、自分の価値観に合う企業とつながる）の両面。
- 規模・登録数・参画社数は更新される数字のため、使うときは最新の資料で確認する（本ファイルに数字は固定しない）。

## 提供コンテンツの考え方
- **「説明会」ではなく「語り合う学びの場」**で、ユーザーとフラットにつながる。「人を奪い合うのではなく、育て合う」。
- **入社のための「仕事紹介」ではなく、人生の未来サンプルとなる「生き方ライブラリ」**。ユーザーは気づきをシェアして志を深める。
- 志企業図鑑：企業のミッション・パーパス・社会課題から分類した15のソーシャルテーマで構成。目に見える業種・業態ではなく、本質的な目的で分類する（志を考えるきっかけ＋マッチング）。
- メディア編集ポリシー（5軸）：VISIONARY（使命・ビジョンが経営の1丁目1番地）／INTEGRITY（知行合一）／HUMANITY（人を尊重）／ORIGINALITY（常識をくつがえす創造性）／SUSTAINABILITY（長期的・全体的利益）。
- 外部の識者による、カリキュラム監修・企業選定・編集委員（共創パートナー）がいる。

## 採用課題の型と、visionsでの解き方
| 型 | 状況 | 打ち手の方向 |
|---|---|---|
| 地方企業の志に、新しいルートを | 認知度、媒体の集客コスト、承諾後辞退。エリアを越境した接点が欲しい | 「いい会社」としてのブランド認知＋コミュニティ経由の母集団形成 |
| 規模より想いの大小で勝負 | マス媒体では、安定感・成長度に惹かれる学生が多く、理念経営の理解に労力がかかる | 採用ブランディングのコンテンツを活かし、マッチ度が高い学生と出会う |
| 仕事の本質的意義を伝え、深い部分でつながる | 業界イメージ、保護者の反対（飲食、医療、介護など） | 志をモノサシに、仕事の意義をブランディング |
| 理念共創人材を獲得（一世代一人） | 少数精鋭。ナビ媒体を使わず、自社に合う学生を1本釣りしたい | 人事管掌役員の面談ルート、異業種コラボ、イメージを裏切るコンテンツ |
| 通常の媒体では出会えない、とがった人材へ | 量は足りているが、事業開発や経営の中枢を任せたい層へ | 志を軸に企業の本質を深く伝える |

## 施策のパターン（案を出すときの引き出し。クライアント名は伏せる）
- **社員登壇イベント**：馴染みの薄い職種の魅力を、学生がイメージしやすい言葉に翻訳する。例：「話し上手より聞き上手が活躍」「じっくり人と向き合い伴走する」。
- **イメージチェンジ型のコンテンツ**：「老舗ものづくり」→「最新のTECH×ものづくりで挑戦を続ける企業」、「パンダのテーマパーク」→「エデュテイメントの企業」（「脱・パンダ採用」）。企業の別の顔を見せる。
- **ブランド体感型インターン**：「なにもしないインターンシップ」のように、理念・採用ブランドを象徴する体験。冬季インターンでプレエントリーが多数集まった例。
- **業務知見のワークショップ化**：自社のメソッド（例：組織づくり、在宅医療での「自分らしさ」を引き出す方法）を、学生の自己分析・学びに昇華し、企業説明会の場にしない。
- **ソーシャルテーマ軸の異業種コラボ**：同じ社会課題を持つ企業同士で登壇する。
- **実践型インターンシップ**：「なんも決まっとらん」ゼロから企画する復興プロジェクト（企画→実現。生産者との協力）、企業の施設を開放し、学生が企画・開催する「ヨコク式」（自律＆協働の実験）。「自由には責任が伴う」と実感する体験。
- **越境学習プログラム**：環境など社会課題を軸に、学生と企業、企業と企業の垣根を超えて学ぶ。
- **面談の設計**：志望度が低い状態でも、まずカジュアル面談につなぐ。選考状況をこまめに共有し、診療同行や面談などで意向を高める。

## プランの考え方（金額は書かない。最新の料金表を確認すること）
- 成果報酬型（価値観フィットする人材をピンポイントで紹介）／スタンダードな年間協賛プラン／リーダー層の育成を共創する少数精鋭プランの3種。
- 含まれる要素の例：個別送客、オリジナル講座・プログラムの企画実施、イベント集客広告の制作・運用、大学キャリアセンター開拓、月次のカスタマーサクセスサポート。
- オプション：経営者記事（ソーシャルテーマ考）、社員記事（生き方学）、志企業図鑑。

## SPDでの使いどころ
- **ターゲット・ペルソナ**：志向性（規模や知名度より、価値観・意義・成長を重視する層）。
- **課題の整理**：上の「採用課題の型」のどれに近いかを判定してから、案を出す。
- **コンセプト／表現**：「説明ではなく学び」「仕事紹介ではなく生き方」「他社の違いを描く」「イメージを良い意味で裏切る」。
- **コンテンツ案**：登壇イベント、体感型インターン、ワークショップ、記事（経営者／社員）。
- 注意：成果の数字（接続・内定・承諾）は案件ごとに条件が違う。他社事例の数字をそのまま、見込みとして提案しない。
