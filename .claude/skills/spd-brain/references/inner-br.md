# インナーブランディング（2026年9月リニューアル版）

## リニューアルの要点（旧版との違い）
1. **目的＝成果の明示**：「叶え合う組織をつくること」自体が目的に見えていた → 「なんのための活動か」というWHYを示す。単なる理念浸透にとどまらない。
2. **理念浸透の解釈拡大**：社内（社内活性・育成・人事）だけでなく、社外にも浸透させる活動。アウター・インナーの全領域が対象。
3. **ポイントの変更**：バームクーヘン（領域の同心円）の図と、ビジョンエンゲージメントをメインに。風土づくり等はアドバイザリーで話す内容として企画書から外した。
4. **STEPの変更**：「言語化・仕組み化・習慣化」の既存フレームに統合し、各領域に言及する。（アドバイザリー＝インナーBR、とも言える）

## なぜ取り組むのか
- 理念を軸に、社員の意識と行動を変え → 組織風土・文化を変え → 顧客への提供価値を変える。結果、人・組織・ブランドという無形資産が育つ。
- インナーの変化：エンゲージメント向上、自律性の向上、離職率の低下、コミュニケーションコストの低減。アウターの変化：理念を軸としたイノベーション、長期的なファン層の獲得。
- **キーコンセプト＝叶え合う組織**：企業の志と社員の志を重ね、「企業→社員（自己実現の支援）」「社員→企業（ビジョン実現への貢献）」の相互の貢献。

## 2つのアプローチ
### A. 組織へのアプローチ
- POINT1：理念やビジョンを、組織の中心に据える（言行一致）。領域の整理：営業／品質管理・向上／事業・商品・サービス／マーケティング・広報PR／組織風土・文化／人事・労務／育成／採用。
- POINT2：成果と課題を見える化し、継続的に活動する（サーベイ：visions survey）。
### B. 個人へのアプローチ
- POINT1：**3つのエンゲージメント**を高める。ワーク（日々の仕事への熱意）／組織（組織への愛着・貢献意欲）／**ビジョン**（会社の目指す未来への貢献意欲）。
- POINT2：「価値観・強み・ありたい姿」の相互コミュニケーション（相互認知 → 相互共感 → 相互貢献）が、エンゲージメント向上の鍵。
- 施策：**My Vision Program**＝自分のありたい姿と理念の重なりを見出し、「何のためにこの会社で働くのか」を自分の言葉で語れる人材を育む研修。

## ステップ：言語化 → 仕組み化 → 習慣化
- STEP0 言語化：理念の策定
- STEP1 仕組み化：理念を具体的な目標に落とし込む（**KBI**：ビジョンから逆算したブランド戦略指標。売上・利益のKGIに加えて、ブランディング観点の質の指標を経営計画に入れる）
- STEP2 仕組み化：各セクションに理念を落とし込む（**マネジメントポリシー**＝WHY理念／HOWポリシー／WHAT施策。事業マネジメントポリシーと人財マネジメントポリシー）
- STEP3 習慣化：仕組みを運用し、改善し続ける（サーベイを起点にPDCA）
- 順番を飛ばさない：「一足飛びに理念を軸に一丸となる組織は実現できない」。

## 領域ごとの施策例（案を出す棚卸しに使う）
| 領域 | 施策例 |
|---|---|
| 組織風土・文化 | 理念ムービー、ブランドブック、ブランドサイト、社内アワード・表彰制度、社内報・社内SNS、ナレッジマネジメント |
| 人事・労務 | 評価制度（理念を評価軸に）、等級・報酬制度、労働環境・オフィス、独自の福利厚生 |
| 育成 | ビジョナリーリーダー育成、全社員向け理念研修（My Vision Program）、階層別の育成制度、タレントマネジメント |
| 採用 | 人材要件定義、採用戦略・コンセプト開発、採用コミュニケーション設計、オンボーディング設計 |
| 事業・商品・サービス | 理念を軸にした既存事業の進化、象徴事業・商品・サービス開発 |
| 営業 | ブランドパートナーの定義、理念から語る提案資料・トークスクリプト、営業プロセスの型化 |
| マーケティング・広報・PR | ブランド戦略策定、コミュニケーションガイドライン、ツール設計・制作、運用 |
| 品質管理・CS向上 | CS活動の設計、品質保証体制、顧客の声が社内に届く仕組み |

## KBIの型（案件名は伏せる）
- ミッションを、アウターKBIとインナーKBIの2つの未来に分ける。例：アウター＝「描いた人生の景色 年間1000ストーリー」、インナー＝「〇〇エキスパート 10名」（新たな価値を生み出す社員を称える）。
- 問い：この会社の志は、お客様側の数字と社員側の数字に、それぞれどう置き換わるか？

## 「結局、何からやればいいのか？」への答え（想定質問）
- その会社の行きたい未来と状況による。but、正確な施策を打つには、現状の正確な把握（サーベイ等）が先。

## 発想に使う問い
- 「理念と現場の言行一致が崩れている場所はどこか？」
- 「社員が、自分の言葉で『なぜこの会社で働くか』を語れているか？」
- 「個人のありたい姿と会社の向かう先は、どれだけ重なっているか？ それをどう測るか？」
- 「どの領域から着手すると、他の領域に波及するか？」
