# LOCAL LONG LIFE インターンシップ チラシ（A4 両面）

LPをベースにした両面チラシです。

- 表面：訴求（キービジュアル・コピー・得られること・開催概要・申込）
- 裏面：1日の流れ（ミッション・タイムテーブル・会場案内）

## ファイル
- `index.html` … 元データ（ブラウザで開く。印刷すると A4×2ページ）
- `flyer.pdf` … 印刷用 A4 PDF（2ページ：1枚目が表、2枚目が裏）
- `flyer-front.png` / `flyer-back.png` … 約300dpiのプレビュー画像
- `assets/` … 画像素材

## 公開前に差し替える箇所
- 申込フォームのQRコードとURL（表面 `.qr` / `.entry__url`）
- お問い合わせ先（表面 `.brand`）
- 交通費補助の上限・条件

## PDFの作り直し
`index.html` を編集後、Chromiumで A4・背景グラフィックありで印刷（`@page` でA4指定済み）。
