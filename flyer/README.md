# LOCAL LONG LIFE インターンシップ チラシ（A4 両面）v2

検証（学生向け採用チラシの基準との照合）をふまえた修正版です。

- 表面（A案）：何の会社か（介護×福祉用具）・参加後に得るもの・数字・申込（締切／定員）
- 表面（B案・比較用）：KV部分だけ「人の顔」を主役にした版（画面表示のみ。PDFには出ません）
- 裏面：1日の流れ（4ブロック）・先輩の声・こんな人におすすめ・選考との関係

## ファイル
- `index.html` … 元データ（ブラウザで開く。印刷すると A4×2ページ＝A案の表＋裏）
- `flyer.pdf` … 印刷用 A4 PDF（1枚目：表A案、2枚目：裏）
- `flyer-front-a.png` / `flyer-front-b.png` / `flyer-back.png` … 約300dpiの確認用画像
- `assets/` … 画像素材

## 公開前に確認・差し替える箇所（オレンジ文字＝仮記載）
- 申込の締切・定員
- 選考との関係の文言（1日完結は「オープン・カンパニー」類型で、採用選考には使えない取扱い。人事で最終確認）
- 「インターンシップ」の名称（KV画像内の文字は画像のため、変更する場合は画像の差し替えが必要）
- 申込フォームのQRコード・URL（現在はダミー）、お問い合わせ先
- 先輩の写真・名前・コメントの掲載許可

## PDFの作り直し
`index.html` を編集後、Chromiumで A4・背景グラフィックありで印刷（`@page` でA4指定済み）。
