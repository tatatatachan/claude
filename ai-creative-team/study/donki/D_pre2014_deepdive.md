## 年別の追加事実

### 1999(旧サイト存在の証跡)
- donki.com のトップページに1999-04-29付のWaybackスナップショットがある。ドンキ公式サイトが少なくとも1999年4月には存在した証跡[#D13]。内容は未読。

### 2000
- donki.com トップに2000-03-02付スナップショット(2002-03-24付もあり)[#D13]。内容は未読。採用との関係は不明。

### 2003(旧採用ページ存在の証跡)
- www.donki.com/recruit/index.html に 2003-02-22 付スナップショット[#D13]。公式サイト内に recruit ディレクトリが2003年初頭には存在したことの証跡。内容(新卒向けか、パート・アルバイト向けか)は未読のため、採用ブランディングの有無は判断不能。

### 2005
- donki.com/recruit/ に 2005-06-27 付スナップショット[#D13]。これが availability API で得られる /recruit/ の最古。
  - 注: 2003-02-22 の index.html が先にあるため、/recruit/ の最古が2005とは限らない(APIは指定時刻の最寄りを返すだけ)。

### 2007
- www.donki.com/recruit/shinsotsu(「新卒」を意味する語を含むURL)に 2007-02-03 付スナップショット、2007-12-24付も存在[#D13]。2007年2月時点で新卒用ページがあった可能性を示す手がかり。ただし内容未読で、URL名のみからの推定(確定ではない)。
- 同URLに 2008-04-30 付スナップショットもあり[#D13]。

### 2008
- donki.com/recruit に 2008-01-10 付スナップショット[#D13]。

### 2009-2012
- donki.com/recruit に 2009-12-30 付(2010-02-08 付 index.html もあり)、2012-01-02 付スナップショット[#D13]。2014-01-01指定で返った最寄りも 2012-01-02 付であり、2012年以降の /recruit/ のスナップショットは availability API 上では見つからなかった(別URL構成に移行した可能性。未確認)。

### 2013(採用キャッチコピー集)
- 2013-12-01 公開の「2015年度新卒採用キャッチコピー100選」に、ドン・キホーテの掲載なし[#D12]。業界の採用コピーを集める定番まとめにドンキは入っていなかったという事実のみ(実施がなかったことの証明にはならない)。

### 2015 (対象外だが年表の起点として参考)
- 日刊工業新聞(2016-03-02)によれば、同社は2015年度新卒採用から履歴書の提出を廃止し、応募者全員と面接する方式で、学歴にとらわれない人物重視の採用を行うと説明。2017年度新卒向けに「逆転採用」(不合格者の再応募可)を発表(2016-03-01)、採用予定は約400名[#D6]。(Bに履歴書廃止の記述はあるが、約400名の数値と「全員面接」の表現はこの出典で確認できた。)
- PRESIDENT(2015-10-20掲載)に、創業者が小売の経験者・プロを雇わず素人に任せた旨の記述(「プロや経験者を雇えば、他のディスカウントストアと同じ店になってしまう」趣旨)。年の特定はなし[#D8]。Aの「素人同然」記述の裏付けにあたる。
