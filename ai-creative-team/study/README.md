# 毎日の学習(デザイン・コピー)

AD/CD/サムネ担当が、日本の有名なデザイン会社・コピーライター会社のWorksを毎日1社ずつ読み込む。

## 対象(初期リスト。追加・削除は人間が指示する)
- デザイン: 日本デザインセンター / SAMURAI(佐藤可士和) / groovisions / DRAFT / 博報堂デザイン
- コピー・クリエイティブ: POOL(小西利行) / SIX(大八木翼) / vivision(児玉裕一) / CHOCOLATE Inc. / OND'
- 基準点: パラドックス(学習済み。[paradox-synthesis.md](paradox-synthesis.md))

## 1日の進め方
1. `daily-log.md` を見て、次の1社を決める(ローテーション)
2. 公式サイトのWorksを3〜5件読む(本文と、取得できる画像)
3. `notes/YYYY-MM-DD_会社名.md` に、次の項目で記録する
   - 作品名/クライアント/年、課題、コンセプト/コピー、表現(色・書体・構図・素材)、採用への転用案、サムネへの転用案
   - 画像が見られた作品は、[ad.md](../ad.md) の評価シートで採点する
4. `daily-log.md` に1行追記し、気づきが蓄積したら `../learning-log.md` と指示書に反映する

## ルール
- ページから読み取れた事実だけを書く。見ていない画像の印象を創作しない
- 他社作品の画像や長文を、そのまま保存・転載しない(URLと自分の言葉の要約にとどめる)
- 一度に深追いせず、1日1社で続ける
