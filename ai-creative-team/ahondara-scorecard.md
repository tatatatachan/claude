# 検品会「わかりやすく・あ・ほん・だ・ら」採点票(AD評価で使う)

出典(社内): 検品会審査シート_26年7-9月納品分(列見出し)、Slack #24年度検品会 のピロートーク告知(2025-04-08)、検品会についてのスライド(260907)。**採点の中身(各案件の点数・コメント・人名)は持ち込んでいない。** 形式だけを写している。

## 1. 検品会とは(分かった範囲)
- 四半期ごとに、納品した制作物を**プロジェクト単位**で審査員が採点する会。審査員は各項目を個別に採点し、検品会で点数とコメントをすり合わせる(「評価会議調整後平均点」)。
- 納品データはプロジェクトごとのフォルダ(`1_納品物 / 2_企画書 / 3_素材類`)に格納する。バラバラに入れると個別に採点され、PJとしての点数が付かない。
- **10点以上**が「お手本」(10点超え作品を語る会がある)。社内の個人目標にも「検品会で10点以上」がある。

## 2. 採点方法(一番簡単な説明)
各項目を **0〜3点** でつける。

| 点 | 意味 |
|---|---|
| 0 | 要改善 |
| 1 | ふつう |
| 2 | いいね〜 |
| 3 | 超いいね!!(感動レベル) |

評価項目は審査シートの列見出しで**6つ**。合計(満点は6項目×3点=**18点**。この満点は列見出しからの私の計算で、シートに明記された値は未確認)。

| # | 項目(シートの列名) | 「わかりやすく・あ・ほん・だ・ら」との対応 |
|---|---|---|
| 1 | わかりやすさ | **わかりやすく** |
| 2 | 新しい挑戦 | **あ**(あたらしさ) |
| 3 | 本質的 | **ほん**(ほんしつ) |
| 4 | 妥協がない | **だ**(だきょうなし) |
| 5 | らしさ | **ら**(らしさ) |
| 6 | 貢献インパクト | (「あほんだら」の外にある6つ目) |

最後に「評価コメント」欄に、良かった点と学びを書く。

## 3. 見るときの問い(**私の言い換え。社内の正式な定義は未確認**)
各項目名から、AD/サムネ担当が使える問いに言い換えたもの。正式な定義が分かったら差し替える。

| 項目 | 問い | 3点の目安(仮) |
|---|---|---|
| わかりやすさ | 初めて見る人が、3秒で何のためのものか分かるか | 説明なしで伝わり、しかも印象に残る |
| 新しい挑戦 | 今までの自社/業界にない表現・手法・視点があるか | 「その手があったか」と思わせる |
| 本質的 | 表面の装飾でなく、課題の本質を突いているか | 依頼の裏の目的まで解いている |
| 妥協がない | 細部まで詰め切ったか(言葉、余白、素材、仕上げ) | 見落としや逃げが一つもない |
| らしさ | その会社/その人でしか成立しないか | 他社に差し替えると成立しない |
| 貢献インパクト | 成果(応募、承諾、認知、離職、現場の声)に効いたか | 数字か声で、効いたと言える |

## 5. ADの運用
- [ad.md](ad.md) の8項目は、デザイン面の細かいチェック用。**社内の合否・お手本判定は、この6項目(0〜3点)で行う。**
- サムネ評価では、この6項目で全体点をつけたうえで、ad.md の「タイポ」「余白」「縮小で読めるか」を補助として使う。
- 制作物は**プロジェクト単位**で採点する(サムネ単体だけでなく、動画や企画書とセットで見る)。

## 6. 未確認・次に確認すること
- 各項目の**正式な定義と3点の基準**(検品会の趣旨説明スライド、審査シートのセルのメモ、アフタートークの録画に書かれている可能性)
- 満点が18点か、他の補正があるか
- 「あ」が「あたらしさ」であること(社内Slackの質問文に「あたらしさ」の語あり。シート列名は「新しい挑戦」)
