# サムネ改善の試作(2026-10-24)

[虎ノ門広告祭の評価](../reviews/) で見つかった弱点を、HTML/CSSで組み直した試作。**写真は差し替えのダミー、登壇者名はダミー(登壇者A〜E)。** 実際の素材・人物写真・公式ロゴは使っていない。サイズは1280×720(縦はShorts用の1080×1920)。

| ファイル | 直す対象 | 変更点 |
|---|---|---|
| a_podcast.png | Podcast「スターがかがやく前夜」(平均7/15) | 下半分を黒帯にし、連番(黄)+氏名(白、極太)+シリーズ名を大きく。細い白文字を廃止 |
| b_interview.png | インタビューShorts(平均5.7/15) | 自動フレームをやめ、専用カバー。上帯に「Vol.」、中央に顔、下に質問と氏名 |
| c_announce.png / c_announce2.png | 告知映像 #01/#02(同一画像) | 番号を円の中に入れ、縞の向き(横/縦)も変えて、一覧で区別できる |
| d_creators.png | クリエイターズ・ナイト(平均7.6/15) | 名前の壁をやめ、主役6枠(肩書き+名前)に整理。残りは「ほか」 |
| e_ycs.png | ヤング・クリエイター・ショーケース(平均8.2/15) | 日本語タイトルと日時を大きく、DAY番号は主役のまま |
| f_nyumon.png | 虎広入門(平均9.4/15) | 登壇者名と肩書きとテーマ(問いの1行)を主役に。マスコットは小さく |

## 作り方
- フォント: Google Fonts の Dela Gothic One / Zen Kaku Gothic New / Shippori Mincho B1。ローカルにダウンロードして `fonts_local.css` で読み込んでいる(容量が大きいためリポジトリには入れていない)。再現するには、各ファイルが読む `fonts_local.css` を用意するか、Google Fontsの `<link>` に置き換える。
- 書き出し: `node shot.js`(Playwright)。

## 次の手順
実素材(写真、実際の登壇者名)に差し替え、別のレビュアーが検品会の5項目で採点してから使う。ダミーの試作は採点していない。
