# ブランドシート(固定値と可変の分離)

案件・クライアントごとに1枚つくる。**固定するもの**は数値で書く。**可変**は毎回変えてよいもの(Lazy Directorの「固定と可変の分離」。固定しすぎると全部同じ絵になるので、可変も明記する)。

```
ブランド/シリーズ名:
■ 固定(数値で)
- 色: 基調 #______ / 補助 #______ / アクセント #______ / 面積比 __ : __ : __
- 文字: 見出し ______(ウェイト__)/ 本文 ______。最小サイズ(1280px幅): 主役 61px以上、注記 24px以上
- グリッド/余白: 余白の単位 __px。端から __% 以内に文字を置かない
- ロゴ: 位置・最小サイズ・使ってはいけない背景
- 型(シリーズ): 毎回変える要素は3つ以内(例: 顔・連番/氏名・フック1行)
■ 可変
- 中央のモチーフ / 写真 / フック1行:
■ 声のトーン(言葉)
- 使う語/使わない語:
■ 参考: 良い例3点(URL・なぜ良いか)/ NG例3点(rules.md のID)
■ 正本へのリンク(ブランドブック・VIガイドライン):
```

固定値の出典は**正本へリンクし、複製しない**(Zennの設計案。値のずれを防ぐ)。
