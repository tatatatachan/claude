# AIクリエイティブチーム

パラドックスの制作範囲(理念開発・ブランディング。ロゴ/VI/Web/紙/空間/映像)を土台に、**採用ブランディングを主軸**にしたAI社員チーム。

| 役割 | 担当 | 指示書 |
|---|---|---|
| CD(クリエイティブディレクター) | 「何を・誰に・どう感じさせるか」を決める。コンセプトと方向性 | [cd.md](cd.md) |
| AD(アートディレクター) | 「どう見せるか」を決め、出力を評価して差し戻す | [ad.md](ad.md) |
| サムネ担当 | 動画・記事・イベント告知のサムネイル量産と勝ち筋の検証 | [thumbnail.md](thumbnail.md) |

## デザインハーネス
制作・検証・評価・記録のループは [design-harness/](design-harness/) にまとめた(世界の調査にもとづく設計)。

## 基本フロー

1. 人間が案件の依頼と素材(企業情報、志、写真など)を渡す
2. **CD**: ブリーフ → コンセプト案を3つ → 人間が1つ選ぶ
3. **AD**: ビジュアル方向性(トーン、色、タイポ、レイアウト)を決め、制作させる
4. **AD**が自分で作らず、**別ステップで**評価シート採点 → 差し戻し(最大3周)
5. 人間が最終判断。採用/不採用と理由を `learning-log.md` に追記し、指示書を更新する

## Adobe無しで出力レベルを上げる方針

品質は「ツール」よりも「文字・余白・素材」で決まる。次の分業にする。

- **文字とレイアウトはAIの画像生成に任せない。HTML/CSS(または Figma / Affinity)で組み、PNG/PDFに書き出す。**
  日本語の文字崩れがなくなり、グリッドと余白を数値で管理でき、テンプレ化と量産ができる。
- **画像生成は背景・質感・イラスト素材だけに使う。** 候補は Midjourney、Ideogram、Flux、Gemini 系の画像モデル、Recraft(ベクター)。契約と商用利用条件は導入前に確認する。
- **人物は実写を優先する。** AI生成の人物写真は採用の「信頼」を損なう。社員の実写を使い、AIは切り抜き、補正、背景にとどめる。
- **仕上げツール**: Figma(無料枠あり)、Affinity(Canva傘下。無料提供の有無は最新を確認)、Photopea(ブラウザ版の簡易Photoshop)、Inkscape、Krita。
- **フォント**: Google Fonts(Noto Serif JP / Noto Sans JP / Zen 系 / Shippori Mincho など)。商用可で、ウェイトが豊富。
- Adobeを契約すれば効果が大きい場面(CMYK入稿、InDesign組版、厳密なベクター編集)は、人間のデザイナーに任せるか、必要になった時点で最小プランを追加する。

## 画像を見て評価するための条件

ADの評価精度は、**書き出した画像を実際に見られるか**で決まる。制作 → PNG書き出し → 画像として読み込んで採点、の流れを必ず通す。文章の説明だけで評価させない。
