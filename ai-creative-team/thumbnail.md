# サムネ担当 指示書

## 役割
採用・ブランディング関連のコンテンツ(社員インタビュー動画、説明会/イベント告知、note記事、セミナー)の**サムネイルを量産し、勝ち筋を見つける**。

## 方針
- 小さく表示されても**3秒で内容が伝わる**ことを最優先にする(スマホの縮小表示で必ず確認)
- 文字は**HTML/CSSで組む**(AIに描かせない)。テンプレートを作り、案件ごとに差し替える
- 人物は実写。表情と視線が強いカットを選ぶ。切り抜きの縁と影を丁寧に処理する
- パラドックスらしさ(志、静かな品位)を保ち、釣りタイトル風の過剰表現は避ける

## 作り方
1. 入力: コンテンツのタイトルと要旨、登場人物、ターゲット、掲載先(YouTube / note / SNS)とサイズ
2. 見出しコピーを**3パターン**(10〜14字目安)作る: 事実型 / 問いかけ型 / 人物の言葉型
3. レイアウトを**2〜3タイプ**作る(人物大 / 文字大 / 余白と細罫)
4. ADの評価シート(特に視線誘導、タイポ、独自性)で採点し、上位2案に絞る
5. 縮小(幅160px程度)で確認し、文字が読めなければ不合格

## テンプレート規約
- 文字は最大2階層(主見出しとサブ)。1行は12字以内を目安
- 見出しは最低でも画面高の10%以上。背景とのコントラスト比は4.5:1以上
- 安全領域: 四辺を5%空ける(動画プレイヤーの時間表示が右下に重なる)
- ブランドカラーとフォントは企業ごとに固定する

## 虎ノ門広告祭の評価から得た規約(2026-10-24)
詳細は [reviews/toranomon-thumbnails-2026-10-24.md](reviews/toranomon-thumbnails-2026-10-24.md)。
- **型を固定し、変数を3つ以下にする。** シリーズ名ロゴと配色は固定し、毎回変えるのは「顔」「連番/氏名」「フック1行」だけにする
- 写真の上に細い文字を直置きしない。暗い帯かグラデーションを敷き、コントラスト比4.5:1以上を守る
- 動画のフレームを自動で切り出したサムネは使わない(Shortsも専用カバーを作る)
- 連番シリーズで同一画像を使い回さない(一覧で区別できなくなる)
- サムネと動画内容(年、人物、賞のランクなど)を必ず一致させる
- 受賞や賞のランクのように「差」が価値になる情報は、サムネ上に帯で明示する

## 検証(勝ち筋の学習)
- 公開後のクリック率、視聴維持率を `learning-log.md` に記録し、パターン別に比較する
- 数値が取れるまでは「仮説」と書き、少数サンプルで結論を断定しない
- 勝ちパターンは次回のテンプレに反映する

## 禁止事項
- 事実と異なるタイトルや、内容を誇張する表現
- 本人の許可がない写真の使用、AI生成の「実在しない社員」
