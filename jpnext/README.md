# JPネクスト案件｜情報まとめ

ジェイピーネクスト株式会社（名古屋市中川区。粉体の空気輸送・真空輸送、マテハン、サニタリー、選別機器）の採用ブランディング提案に使う情報を、ここに集めています。
ホシザキ案件（`hoshizaki/`）と同じ型で、市場・ターゲットのリサーチとSEEDSの整理を行いました。
最終更新：2026-10-27

## 案件の要点（Slack・8/4ヒアリング・提案デッキより）
- 2025年にPARADOXで理念（MI）を策定し、11/21にリリース会。ブランドムービー納品済み。VI（ロゴ）策定が進行中（11月上旬ロゴ提案→12月上旬FIX）。新オフィス（リノベーション）も進行中。
- 採用の課題：①媒体・人材紹介のコスト ②営業の慢性的な不足（ニッチ業界で経験者が少なく、1人立ちまで3年）③新卒を採るリソース不足。過去に新卒2名を採用し、OJT体制が整わず2名とも退職。
- 先方の希望ターゲット：新卒より**第二新卒（社会人2〜4年目）**。素直に学ぶ人。現場経験者→営業も好相性。30〜40代の拠点を担う中堅も採りたい。
- visions（登録約6,000名）に関心。年間160万円（1名分の紹介手数料込み）。「松竹梅」の見積と採用実績データを先方が要望。
- **10/28（水）17:00〜18:00 オンラインで提案**（小阪さん。社長同席は未定）。10/22の社内方針：この回はコンセプトを出さず「誰に何を届けるか」のヒアリング機会にし、11月前半に若手3〜4名を取材→12月上旬に社長へ採用コンセプト仮案。
- 齋藤さんの方向性案：エフビー型の採用ブランディング A：320万円／B：360万円。新卒・中途を含む採用ブランディングとして設計（10/22合意）。
