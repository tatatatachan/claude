# スライドのデザインルール（PowerPoint）

参照図版：「イベントの流れ」「この体験で得られる3つのこと」「Program」。
このルールは、実習まわりのスライド（事業所アンケート、実績のまとめ）で確定した形。以後のスライドはこれに合わせる。

## 色
| 用途 | 色 |
|---|---|
| ヘッダー帯・グラフの棒・区切り線 | ミント `#55C5B0` |
| 山の模様 | 明るいミント `#70CEBC` |
| 見出し（章・列）・強調 | 濃いミントグリーン `#2F9D89` |
| 本文・タイトル（白地） | 紺 `#323042` |
| 補足・出典 | グレー `#6B6A7A` |
| 小さな強調ラベル（PARTなど） | オレンジ `#F28A3C` |
| 背景 | 白 `#FFFFFF` |

クリーム色・ベージュの背景は使わない。

## レイアウト
- 背景は白。
- 上にミントのヘッダー帯（高さ約1.25in）。左上に小さな英字（大文字・字間広め・白）、その下に白抜きのタイトル（30pt・太字）。右に薄い山の模様。帯の下端は白い楕円でゆるい波にする。
- 丸枠・角丸カード・囲み線は使わない。内容はスライドの横幅いっぱい（左右0.6in）に置く。
- 最下部の帯は付けない（白）。
- フッター：左にコピーライト、右に出典。10pt・グレー。

## 表
- 列見出し：濃いミントグリーンの太字。その下に同色2pxの線。背景の帯は付けない。
- 行の区切り：ミントの点線（`sysDot`）。縦線・外枠は引かない。
- 章の見出し：丸囲みにせず、濃いミントグリーンの太字（本文+2pt）。章をまたぐ枚は「（続き）」を付けて入れ直す。
- 項目名は太字、回答は通常。

## 文字
- フォントは Arial。
- すべて上下中央揃え。同じ行のセルは同じ高さ・同じ y に置く。
- 本文は14pt以上を基本にする。詰め込む場合でも13ptまで。注記は12pt、フッターは10pt。
- 枚数は、文字を小さくしすぎないことを優先して決める。

## 作るときの手順
1. `design/pptx-theme.js` の色と `chrome()` を使う（色を各スライドに直書きしない）。
2. `validate.py` で検証し、LibreOffice でPDFにして画像で確認する（はみ出し、重なり、フッターとの衝突）。
3. 日本語の太字は LibreOffice のプレビューに出ないことがある。PowerPointで最終確認を依頼する。
