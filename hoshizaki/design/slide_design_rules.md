# スライドのレイアウト規則（参考デッキ❶❷を組み込み）

ホシザキの世界観（Quiet Cool。氷とペンギン）に、参考デッキ❶❷の「骨格」と「図解のパターン」を掛け合わせた規則です。
参考にしたのは、UUUMのカンパニーデッキ（表紙、目次、数字で見る共創、クリエイターマネジメント、コンテキスト・ドリブン・マーケティング、支援メニュー、今後の成長戦略、注力ポイント、数字で見る働く環境）。ロゴ・キャラクター・文言は使わず、レイアウトの考え方だけを取り入れています。

## 1. 骨格（キャンバス 1920×1080）

| 部位 | 規則 |
|---|---|
| 右サイドバー | 幅96px（x=1824〜）、色は `deep` #004767。上にペンギンのマーク（仮、正規素材に差し替え）、下にページ番号（BIZ UDPMincho 40px、白） |
| 背景 | 内容スライドは `surface` #F4F7F9（参考デッキの淡い灰青）。表紙・目次・コンセプトの章扉だけ `sky` #00A0E9 の全面 |
| 余白 | 左110px、右はサイドバーを避けて160px、上52px。内容の使える幅はおよそ1,600px、高さはおよそ700px |
| 出典・注記 | 下端（top:1004px）に右寄せ、24px、`body` 色。算出期間・サンプル数・試算の前提を書く |

## 2. 見出しの3段（すべての内容スライド）

1. **トピック見出し**：左上、52px、太字、`sky-text` #0087C6（skyを暗くして白地で約3.9:1にした拡張色）。名詞で短く。
2. **主張文**：中央、44px、太字、`ink`。1行（約34字まで）。「何が言えるか」を言い切る。
3. **補足**：中央、28px、`body`。1行。範囲・条件・出典の種類を添える。

## 3. 面と文字

- **カード**：白、角丸8px、影は `0 2px 10px rgba(0,71,103,0.10)`（参考デッキのやわらかい影。強い影は使わない）。
- **強調帯**：`tint` #E3F3FC の面に、結論や注意を1文。
- **青パネル**：`sky-text` #0087C6 の面に、白い小さなボックスを並べる（コンテキストの見せ方）。
- **数字**：Barlow 700。大きい数字は #0087C6、単位は数字の約半分。ラベルは数字の上、アイコン（線画、`deep`）は中段。
- **文字は24px以上**。小さい青文字は使わない（`sky` #00A0E9は白地で約2.9:1）。

## 4. パターン集（内容に合うものを選ぶ）

| 内容 | パターン | 参考 | 作り方 |
|---|---|---|---|
| 数字で言いたい | 数字カード | ❶ 数字で見る共創 | 白カード3〜6枚。ラベル→アイコン→大きな数字＋小さな単位 |
| 構成要素と関係 | ハブ図 | ❶ クリエイターマネジメント | 中央に円、左右に青い枠のボックス（見出し＋淡い青のチップ）、点つきの線でつなぐ |
| 掛け合わせて説明 | コンテキスト図 | ❶ コンテキスト・ドリブン | 青パネル＋白サブボックス、「＋」「×」で式にする。従来手法は灰色のボックス |
| 段階×手段の整理 | ジャーニー・マトリクス | ❷ 支援メニュー | 行＝段階（左に漏斗）、列＝カテゴリ（灰色の見出しバー）、青い縦ピルのバーが段階をまたぐ。青い細罫で行を区切る |
| 時間の流れ・計画 | タイムライン | ❷ 今後の成長戦略 | 太い青の矢印、白い丸のノード、点線、白カード（右へ上がる段差）。達成は小さなバッジ |
| 階層・領域の分け方 | ピラミッド＋縦矢印 | ❷ 注力ポイント | 左に縦矢印と縦書きラベル、ピラミッドを色の濃淡で分け、右に領域ごとの説明パネル |
| 量の比較・推移 | ダッシュボード | ❷ 数字で見る働く環境 | 白カードを大小で並べ、青い見出し。棒グラフは値ラベル付き、ドーナツゲージは中央に数字 |
| 目次 | Index | ❶ 目次 | 青い全面、明朝の「Index.」、点線リーダー、ページ番号、右端に色タブ |
| 表紙 | カバー | ❶ 表紙 | 青い全面、明朝の英字見出し、版の表記、右に大きなモチーフとキャラクターの列 |

## 5. ホシザキへの置き換え

| 参考デッキ | ホシザキ |
|---|---|
| 青（主色） | `sky` #00A0E9（面）、`deep` #004767（強調・サイドバー）、`sky-text` #0087C6（見出し・数字） |
| 紫・緑・赤（副色、色タブ、バッジ） | 使わない。色タブは `ice`・白・`deep`・`sky-text`。強調の1点だけ `beak` #F59E0B |
| ロゴ | ペンギンのマーク（正規素材。いまは仮の図形） |
| キャラクター | ペンギンの列（正規素材。いまは仮の図形）、氷のキューブ（角丸の四角） |
| 英字の明朝 | BIZ UDPMincho（表紙・目次・章扉・ページ番号） |
| 縦書きの著作権表記 | 使わない（キャンバス内に収まらないため）。出典は下端に置く |

## 6. 守ること

- 1スライド1メッセージ。主張文は1行。
- 出典・サンプル数・算出期間・試算の前提は、必ず下端に書く。仮説は「仮説」と書く。
- 色は3色まで（背景・面・文字）に、強調の `sky` を1点。紫・緑・赤は使わない。
- 影は弱く、グラデーションは使わない（参考デッキの面グラデーションは、章扉のみ）。
- 図解は参考デッキのパターン集から選び、同じ種類の内容には同じパターンを使う。

## 7. このデッキでの適用

- 表紙、目次（Index.）、主張文つきの見出し、サイドバー、数字カード、棒グラフのカード、表、タイムライン（次のステップ）、青パネル（人物像）に適用。
- ハブ図、ジャーニー・マトリクス、ピラミッドは、内容が出たときに使う（現時点のデッキには該当する内容がない）。
