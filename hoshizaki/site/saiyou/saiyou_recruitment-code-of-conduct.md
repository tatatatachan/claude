# Recruitment Code of Conduct｜ホシザキ本社採用サイト

- URL: https://www.hoshizaki.co.jp/saiyou/recruitment-code-of-conduct/
- 概要: ホシザキ本社 採用活動における行動基準。本基準は、採用選考、会社説明会、インターンシップ、リクルーター活動、職場見学、懇談会その他採用活動に関するあらゆる場面に適用します。

Recruitment Code of Conduct
役員及び従業員は、求職者等の人格及び尊厳を尊重し、公正かつ誠実な採用活動を行わなければなりません。
本基準は、採用選考、会社説明会、インターンシップ、リクルーター活動、職場見学、懇談会その他採用活動に関するあらゆる場面に適用します。また、対面による活動のほか、オンライン面接、Web会議システム、電子メール、SNSその他電子的手段によるコミュニケーションを含みます。
役員及び従業員は、採用選考やインターンシップ等における優越的な立場を利用して、求職者等に不快感、不安又は不利益を与える言動を行ってはなりません。
遵守事項
求職者等に対し、次のような言動を行ってはなりません。
(1) 性的な言動等
・性的な言動
・性的な内容を含むメッセージの送信
・性的な内容の情報の流布
・わいせつな画像、動画その他性的なコンテンツの送信又は閲覧の強要
(2) 不適切な接触等
・不必要な身体接触
・不必要な面談、食事、飲酒その他私的な接触
・交際又は性的関係を求める言動
(3) 不適切な質問及び発言
・容姿、服装、身体的特徴等に関する不適切な発言
・結婚、妊娠、出産、恋愛経験その他採用選考に関係のない私生活に関する質問
(4) 個人情報及び通信に関する不適切な行為
・SNSや個人連絡先等の交換の強要
・会社が認めていない手段による私的な連絡
(5) 地位を利用した不適切な行為
・採否への影響を示唆するなど、優越的な立場を利用した不適切な言動
・その他、求職者等に不快感、不安又は不利益を与える言動
なお、上記は例示であり、求職者等の人格及び尊厳を損ない、就職活動に支障を生じさせるおそれのある行為をしてはなりません。
実施ルール
① 面談、面接等は、会社が認めた方法、場所及び時間帯で実施する。
② 面談、面接等は、内容や実施状況に応じて複数名で対応するなど、適切な実施体制を確保する。
③ 求職者等との連絡は、会社が承認した電子メール、採用管理システムその他の連絡手段を使用し、私的な連絡手段を使用しない。
④ 求職者等との連絡及び面談は、採用活動に必要な範囲で行う。
⑤ 懇談会その他の採用関連イベントについては、求職者等の自由意思を尊重し、参加を強要しない。
施行 2026年10月1日
