## 1. ゴール
- エフビー介護の目玉コンテンツとして実習を育てる。長野大学とは「共同授業（STA）」の形を目指す。
- 大学のブランドも上がる実習にする（学び・地域・進路・広報の4つを大学に返す）。
- 実習を出会いと見極めの場にし、採用（選考流入）につなげる。

## 2. 実習ブランドの概念
- 高校・専門学校: 単位があるので「実習」なら学校が受け入れやすい。
- 大学: 介護の学部・学科が減少しており、魅力的な実習は歓迎される。大学向けは **STA (Social Theme Action)**。
- 名前は「実習」を名前の中に入れる方針（学校と繋がりやすい）。
- 現在の案は **「共育実習」**（コピー: ケアの現場で未来を見つける、キャリア探究型 共育実習）。
- 共育の意味: 学生から学ぶ側にも立つ。社員もご利用者さんの生きがいも育つ。

決定事項: 高校・専門学校の受け入れ方と、大学とのコラボ（STA）は別の型として概念化する。次は長野大学を動かす。

## 4. 実習プログラム案
- **DAY1（1日版）**: 受付・オープニング → 現場シャドーイング＆傾聴 → ランチセッション → 対話ワーク『100歳までの履歴書』 → リフレクション。
- **DAY5（5日版）**: DAY1 インストール / DAY2-3 現場ケアと関係構築 / DAY4 利用者さんを笑顔にするプチ企画 / DAY5 履歴書発表会と結びのランチ。
- 学習シートで標準化。標準の導入動画。メンター（学生1〜2名につき1名）。声を実習サイトに蓄積。

## 5. 長野大学との連携
- これまで（2025/12/12 vol.01 提案）: 中村英三先生へ産学連携を提案。「生きがい 持ち寄る 地域の未来」多世代ワークショップ（佐久・24名想定）、単位認定化の協議、9月後半に本格協議開始の目標。
- 現在の運営実行委員の設計:
  - PHASE1 10月〜: 実行委員（長野大学生3名程度）募集（学内ガイダンス数回）
  - PHASE2 11月〜: 企画会議（フィールド=エフビー、企画運営サポート=パラドックス）
  - PHASE3 12月〜: 企画実施
  - PHASE4 12月（冬休み）: レポート提出
  - ミッション: 子どもから高齢者まで地域の人々が集う「生きがい 持ち寄る 地域の未来」を体現する場をつくる
- 大学に返すもの: 学生の企画とレポート、学生・先生の声、成果発表会、共同授業の記録（大学名で使える素材）。
- **次の一手**: 長野大学へ持ち込み（10/23 or 10/27）。アポ取得の件は、現場ではなく社長を含む上層部へ共有する（田島さん提案、10/21）。メール送付は二之宮さん宛て、CCに社長。
